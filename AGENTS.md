# AGENTS.md

## Graphify Integration
Prima di eseguire qualsiasi compito, leggi l'indice e le comunità del knowledge graph.
- Controlla `graphify-out/GRAPH_REPORT.md` per una panoramica dei componenti principali.
- Se una richiesta non è banale, usa il grafo per identificare i file esatti da leggere, invece di fare ricerche alla cieca.

## Istruzioni per il contesto
- Quando modifichi un file, usa Graphify per capire l'impatto su altri moduli.
- Per domande architetturali, fornisci spiegazioni basate sulla struttura del grafo.
- Se trovi sezioni non mappate o relazioni mancanti, usa il comando `/graphify --update` per rigenerare il grafo.
